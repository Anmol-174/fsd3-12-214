 # HTTP Module

 It is built in Node .js which allows developers to create web server and 
 web client without installing any external package.
 one of the most important module in Node.js, orginally desgined for building 
 scalable network application and web servers.

 1. create web server 
 2. handle client request 
 3. Build REST APIs
 4. Non-Blocking I/0
 5. Foundation of Express.js
 
 ## http status codes

 - 200 -> OK
 - 201 -> Created 
 - 400 -> Bad Request 
 - 401 -> Unauthorized
 - 403 -> forbidden 
 - 404 -> Not Found
 - 500 -> Internal Server Error
